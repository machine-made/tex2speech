# Changelog

## Unreleased

## 0.0.1

- Added the `tex2speech` crate and program; `tex2speech --version` prints the version. Exit codes: 0 success, 1 unreadable input, 2 bad command line, 3 output write failure
- Added the Apache-2.0 licence
- Added the English engine: `Document::parse_str`, `parse_file`, `segments`, `select`, `to_text`, `to_json`; the program reads a file or standard input and prints text, or JSON with `--json`
- Added a LaTeX reader (tolerant, byte positions, `\input` and `\include`, macros and environments from any position) and a Markdown reader
- Added `tools/corpus_sweep`, which runs the engine on folders of documents and counts crashes, leaks and warnings by construct
- Added `Options::with_threads` and `--threads`; removed the `T2S_THREADS` and `T2S_TRACE` environment variables and the 64 MiB reader thread (nesting is limited to 32 levels, with a warning)
- Added to `tools/corpus_sweep` a count of poor readings per document
- Added `Document::parse_bytes` and `Document::parse_file_as`; input may be UTF-8 with or without a byte-order mark, UTF-16 with a mark, Latin-1, Latin-9 or Windows-1252 (`inputenc` is honoured, a guess gives an `encoding` warning); a binary file reads as empty text with a warning
- Added a Windows job to CI and a `.gitattributes` that keeps LF in test data
- Fixed bugs: no panic when a multi-byte letter lies 400 bytes after `\documentclass`, nor on an ordinal of 16 digits or more; the 25 built-in terms and user terms with two-digit indices each get their own reading; a panic in the reader gives an empty document with an `internal` warning; a longer Markdown code fence is not closed by a shorter one
- Changed the MathCAT fork: relations lose the leading "is", `/` reads "over", simple compound subscripts lose "sub", and the full Unicode table is read once instead of once per equation
- Changed readings: a pair in parentheses is no longer an interval (`(a, b)` reads "a, b"; `x \in (a, b)` reads "x in the open interval from a to b"), `\vec{v}` reads "vector v", accents read on any base, `\|A\|` reads "norm of A", cases read "a if x greater than 0, b otherwise", matrices and arrays of any size read by rows, `(a)` reads "a", `x^{(j)}` reads "x superscript j", `A^\top` reads "A transpose", `x^*` reads "x star", `E[a, b]` is not an interval, a term such as "Reynolds number" is not said twice, a list numeral such as "(ii)" keeps its case
- Changed the reader: maths commands outside `$` in a fragment or Markdown text read as maths (`\beta = 43000`); a citation after a full stop starts a sentence; `\newenvironment` and `\renewcommand` of TeX internals no longer speak their code; `\let` keeps the built-in meaning; `\ifnum` and `\ifodd` are evaluated; `\orcidlink`, `\DeclareMathAlphabet`, `\fontsize` and similar commands are skipped
- Changed readings: a comma, semicolon or backslash between parts is a pause or "set minus", not a word (`(R, Re_D)` reads "R, Reynolds number D"); `\mathbb{E}[X]` reads "expectation of X" and `\mathbb{P}(A)` "probability of A"; a bar inside brackets reads "given" (`p(x | y)`); `k_\perp` reads "k perpendicular", `A^\perp` "A perp"; `\overbrace` and `\underbrace` read their label; a `vmatrix` reads "the 2 by 2 determinant with rows a, b, and c, d"; `|S|` reads "the absolute value of S"; a single `# 1` is "Chapter 1"
- Changed paths: `\input{sub\file}` finds the file, `Document::select` matches paths that differ in separators, drive letter case, `.`/`..` or prefix, and the program accepts file names that are not UTF-8
- Changed readings after listening to real papers: `H^1(\Omega)` reads "H one of omega" (not "the first power of"), `f^{-1}(x)` "f inverse of x", `\sim` reads "tilde" (and "about" before a number), `\ell` "ell", `y^\circ` "y circle", `M_\odot` "M sun", `\mathbb{Z}_2` "Z two", `\mathbb{S}` "S" (blackboard letters lose "double struck"), `\mathbb{1}_A` "indicator of A", `\rtimes` "semidirect product", `\preceq` "precedes or equal to", `P_1^\mu` is no longer a permutation count; "Ref. [9]" is no longer "Reference, reference 9"; a word that touches an equation in the source ("$\Lambda$CDM") is spoken apart; "i.e." before an equation no longer takes a full stop; spacing commands inside an equation are skipped
- Changed `\input`, `\include`, local classes and packages and `.bbl` files: only files inside the base folder are read; an absolute name, `..` out of the folder or a link out of it is refused with a warning, and with no base folder no file is read
- Changed readings a listener hears: `x_{n+1}` "x sub n plus one", `(a+b)(c+d)` "a plus b, times, c plus d", `(a+b)^2` "a plus b, all squared", `\frac{a+b}{c+d}` "a plus b, over, c plus d" (nested fractions keep "the fraction with numerator"), `(N-2)th` "capital N minus two th", an array after a relation reads as a matrix, `\underline{\mu}` "mu underlined", `\Rightarrow` "implies", `\mathrm{Re}(\lambda)` and a redefined `\Re` "real part of lambda", a word after a number in a subscript is not a unit, `\{x \mid x>0\}` and set-builder conditions with commas "such that", `\left. f \right|_{x=0}` "f at x equal to zero", `\lfloor x \rfloor` "floor of x", the conditions of `\substack` under a sum are joined by "and", a bar between letters is "vertical line"
